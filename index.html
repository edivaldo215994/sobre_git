Conhecendo o Github

O GitHub é uma plataforma de desenvolvimento colaborativo que permite que pessoas do mundo inteiro trabalhem juntas em projetos de software, mesmo que estejam em locais diferentes

O que é o GitHub?

É um serviço baseado em nuvem que hospeda projetos de código usando o sistema de controle de versão chamado Git.

Foi criado em 2008 e atualmente pertence à Microsoft.

É amplamente utilizado por desenvolvedores para compartilhar, revisar e colaborar em código-fonte.

Para que serve?

Controle de versão: permite acompanhar todas as mudanças feitas no código, revertê-las se necessário e entender quem fez o quê.

Colaboração: várias pessoas podem trabalhar no mesmo projeto simultaneamente, sem sobrescrever o trabalho umas das outras.

Hospedagem de projetos: você pode criar repositórios públicos ou privados para armazenar seu código.

GitHub Pages: permite criar e publicar sites estáticos diretamente de um repositório

Quem pode usar?

Desenvolvedores profissionais e iniciantes.
